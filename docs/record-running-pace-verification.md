# 切片 13：查看计算出的跑步配速

日期：2026-09-26。

范围：使用第 12 片跑步记录的时长（分钟）、距离（公里）计算平均配速。仅展示事实，不加入配速评价、目标配速、分段配速或持久化。

## 计算规则

- 平均配速总秒数 = `Math.round(时长分钟 / 距离公里 * 60)`，再拆分成分钟与两位秒数，格式为 `6′00″/公里`。
- 两项都必须是大于零的有限十进制数；空值、非法输入、零时长或零距离不显示有效配速。
- 配速是从当前输入派生的页面字段，不向计划或运动结果存储第二份配速，也不参与运动完成判定。
