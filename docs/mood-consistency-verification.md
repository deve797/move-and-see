# 前后心情选项与运动前文字备注

2026-09-26。按用户要求统一运动前后选项，并在运动前增加选填文字记录。本轮将“语言记录”理解为打字备注，未实现录音。

## 改动文件

- `miniprogram/pages/today/index.js`、`index.wxml`、`index.wxss`：运动前面板增加 200 字选填备注和“完成”；每项运动独立回填；关闭取消本次编辑；卡片提示“有备注”。
- `miniprogram/pages/mood/index.js`、`index.wxml`、`index.wxss`：运动后改成同样的五档按钮与当下心情文案，初始不选；沿用文字备注和返回入口。
- `miniprogram/utils/mood-options.js`、`miniprogram/styles/mood.wxss`：复用选项、表情、选中态及文字输入样式。
- 本记录、四张 `mood-before-notes-*` / `mood-after-five-*` 截图；两份旧验证记录标注已被本次交互取代。

## 行为与范围

今天页每张运动卡片底部“运动前心情”打开原面板。选低落、不太好、一般、不错、很好之一，可填写文字，再点“完成”；也允许只写备注或留空。再次打开回填该运动已确认的内容，关闭/X/遮罩/原生退场不应用本次编辑。瑜伽、跑步彼此独立，不改变完成状态。

原今天卡片 → 运动记录 → 运动后心情 → 返回运动记录的导航保持不变。运动后的标题改为“运动后的心情”，避免把绝对心情选项描述为变化幅度；五档横排与运动前一致。无默认选择，不替用户判断心情。运动前改为点击“完成”收起，为文字输入保留操作时间。复用鼠尾草绿选中态与原生文字控件，全部为可编辑 WXML/WXSS，无新增图片素材。

仅页面实例内的演示状态。没有数据库、请求、本地存储或真实记录提交；重新进入页面恢复空白。40 个非目标小程序文件与本轮备份 SHA256 一致，未改路由或现有运动动画组件。
