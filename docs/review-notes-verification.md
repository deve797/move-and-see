# 本周回看：文字总结与前后原话

2026-09-26。实现用户确认的“简短周总结在前，原话对照点开看”。

## 改动

- `miniprogram/pages/review/index.js`：添加明确标注的总结及四条虚构文字记录；默认收起；展开/收起，底部收起后回到总结位置。
- `miniprogram/pages/review/index.wxml`：在原“心情小发现”中保留次数，增加文字总结、同页展开按钮、按日期/运动配对的原话；缺少前/后备注时省略对应行。
- `miniprogram/pages/review/index.wxss`：沿用浅灰卡片、深色文字和绿色交互；文字占满卡片内宽，原话自然换行，48px 展开按钮与 44px 底部收起按钮。
- 本文、六张 `review-notes-*.png` 截图及旧验证记录的增量链接。

未新增页面、路由、素材或组件；其余 45 个小程序文件 SHA256 与本轮修改前一致。今天、记录、心情页保持原样。无请求、数据库、本地存储或自动文字归纳能力；本次仅供前端形式体验。数字、总结、原话均为固定示例，并在卡片和页尾标注，尚未读取用户填写的备注。

## 展示原则

总结中的五个引用片段均能对应下面的原话；保留“还是有点累”的感受，不只呈现积极变化，不作评价或建议。四条文字示例只代表有备注的运动，不宣称覆盖上方全部五次运动。散步示例只写了运动后，页面不会补写运动前。

沿用现有卡片图标、标题、次数的层级；文字放在其下占满内宽，避免小屏被左侧图标挤窄。原话超过一屏，底部增加“收起原话”，减少回滚操作。所有文字、分隔线、按钮和箭头均由 WXML/WXSS 实现。
