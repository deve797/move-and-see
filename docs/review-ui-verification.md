四周柱形分别为 2、3、4、5 次；摘要显示本周运动 5 次、比上周多 1 次，以及运动后心情变好 3 次。所有数字均为固定示例，并在页面注明。未读取或统计真实记录，未增加请求、数据库、本地存储、主观评价或预测能力。

## 相对概念图的主动调整

1. 使用微信原生导航、返回及胶囊，沿用现有中文“向前动”品牌，保持标题、四周图表、运动摘要、心情摘要的层级。
2. 柱形、数字、标签和卡片均由可编辑 WXML/WXSS 实现，不使用 Canvas 或整页图片；每根柱显示次数，避免只靠高度和颜色传达数值。
3. 复用已有鞋履插画，灯泡改为 WXSS 图形，保持黑白装饰方向且不增加图片素材。
4. 短屏采用自然纵向滚动，并调整图表高度和卡片间距，保留可读字号与操作尺寸；灰字使用较高对比度。
5. 今天页增加轻量入口，回看页底部增加低强调返回按钮，形成完整往返路径；补充固定示例提示，避免将静态界面理解为真实统计。
