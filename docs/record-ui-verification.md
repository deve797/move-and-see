## 相对概念图的主动调整

1. 使用微信原生导航栏、返回与胶囊，省略概念图中的模拟顶栏控件，符合小程序交互。
2. 文字、白色背景、黑色按钮和箭头均为可编辑 WXML/WXSS；仅鞋履插画与橙色落叶使用位图。插画独立重新生成，保留原图视角、黑白方向及橙色点缀。
3. 独立入口保留 32 分钟户外行走；从今天页进入则显示被点击运动的示例名称和时长，避免瑜伽入口展示户外行走。鞋履画面仍作为统一装饰插画。
4. 短屏采用自然纵向滚动，并微调字号、间距及按钮高度；保持阅读和点击尺寸，不强行压缩成一屏。
5. “记好了”只完成页面跳转，下一页提供心情占位和返回按钮；补充简短示例说明，明确当前没有保存记录。未扩展表单、计时或业务能力。
