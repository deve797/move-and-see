## 归属口径

沿用现有“本周回看”的北京时间周一至周日、按原计划日期选取范围。spec 未另定备注跨周归属，因此本轮不新增历史周选择；补做条目显示实际日期，不把备注搬到补做所在周。页面注明该范围。

| 来源 | 展示归属 |
| --- | --- |
| `plan.beforeMoodNote` | 原计划日期、原计划运动、运动前；无结果或未完成也可展示 |
| 正常完成 `result.afterMoodNote` | 原计划日期、原计划运动、运动后 |
| 替代结果自身的备注 | 原计划日期、实际运动、相应前后阶段，另列“替代完成” |
| `result.makeup` 自身的备注 | 实际补做日期、实际运动、相应前后阶段，另列“补做” |

当前录入入口仅产生原计划前备注、正常完成后备注、补做后备注；替代记录自身备注以测试样例验证只读归属，不代表本轮新增了录入能力。原计划前备注不与替代/补做备注拼接。取消计划排除，生理期免考核不隐藏已写备注，独立自愿散步不借用原计划备注。
