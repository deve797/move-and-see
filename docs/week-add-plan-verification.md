# 切片 1：新增一条运动安排

2026-09-26。以本轮用户提供的切片定义为准，不采用 `plan.md` 中云开发里程碑作为本轮范围。

## 本轮范围

在周计划中选择日期、项目、开始时间，确认后显示在对应日期。项目和开始时间初始为空，未填齐时确认按钮禁用；取消填写丢弃草稿。确认后切换到新增日期所在周。

新增安排仅保留在当前周计划页面的内存中。本周、下周及日历选周之间切换不会清空；离开本页后重新进入、重新编译或关闭小程序后不保留。不使用本地存储、云端或数据库。

每条既有示例明确标注“固定示例”，用户新增项标注“我添加的 · 临时”，展示开始时间和项目。原有示例详情入口保留，新增加的安排没有编辑、取消或记录入口。

不实现：修改安排、取消安排、今天页联动、运动记录、持久化，以及切片 2–23。

## 修改

- `miniprogram/pages/week/index.js`：新增表单状态、必填校验、内存中的安排列表；按完整日期合并到周视图。
- `miniprogram/pages/week/index.wxml`、`index.wxss`：新增入口、原生日期/项目/时间选择器、确认及取消填写按钮、临时安排和示例标识。
- `tests/week-add-plan.test.js`：基于实际页面逻辑的自动化验收。
- `PRODUCT.md`：补充本切片的实际能力和临时数据边界。

## 验证结果

| 验收条件 | 自动化检查 | 微信开发者工具模拟器 |
| --- | --- | --- |
| 下周二 19:00 跑步出现在对应日期 | 通过，2026-09-29 仅一条 | 通过，页面读取和截图均显示该日期下的 19:00 跑步 |
| 缺项目或时间不能确认 | 两种缺失情况均通过，直接调用确认也不新增 | 两种情况下按钮 `disabled` 均为 true；填写完整后为 false |
| 取消填写不新增 | 填写完整再取消，条数不变 | 点击“取消填写”后仍只有原来一条 |
| 切换其他周再回来仍在，不串周 | 本周、下周、任意周、跨年检查通过 | 下周→本周无新增项；返回下周仍为原来的跑步 |
| 用户安排与固定示例明确区分 | 原示例内容不被覆盖 | 截图确认“固定示例”与“我添加的 · 临时”分开展示 |

额外检查：确认连点不重复新增；再次打开表单项目/时间清空；同一天可添加两项；跨年新增不会覆盖另一周的安排；重新创建页面不恢复临时安排。

运行命令：

