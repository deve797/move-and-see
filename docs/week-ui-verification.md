# 周计划 UI 交付记录

2026-09-25。依据《向前动概念图.png》上排第三页“下周怎么动？”。

## 本轮内容

新增周计划页、详情占位页；保留中文品牌、衬线标题、七天纵向列表、日期分栏、灰绿/橙红状态点和右侧黑白小插画。所有文字、背景、按钮、日期选择器、分隔线及状态点使用 WXML/WXSS。只有七个装饰插画使用一张独立 PNG，通过容器显示对应区域。

列表为固定界面示例，不读取或保存真实计划。日历默认展示设备当地日期的下周；选择任一日期展示其所在周，只有页面内状态变化。重进页面恢复默认下周。不接数据库、网络、云函数、本地存储或真实排班逻辑。详情页仅展示点击行的信息和占位说明。

入口：首页 → 看看今天 → 看看下周安排 → 点击任一天 → 返回周计划。保留原生导航返回。

## 相对概念图的主动调整

1. 延用“向前动”中文品牌与现有共享样式，不将英文参考名称当作更名。
2. 使用微信原生顶部导航、返回与胶囊；日历通过原生日期 picker 选择所在周，日历图标由 WXSS 绘制。
3. 参考图的固定 4/21—4/27 改为默认下周的真实日历日期，并增加一行周范围。运动名称和时长仍为明确标注的示例。
4. 保留列关系和行内层级；320px 缩小日期栏、插画和部分字级，短屏纵向滚动，不强行压缩七天到一屏。
5. 右侧插画按参考重新生成，非原图像素复制；没有把整个页面或文字做成图片。
6. 各行扩大为整行点击目标，详情只做占位，不加入未授权的编辑或保存业务。
