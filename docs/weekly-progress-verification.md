# 切片 18：查看本周完成进度

日期：2026-09-26。范围依据 `切片.md` 第 18 片。

## 修改

- 新增 `miniprogram/utils/weekly-progress.js`，输入临时计划、日期生理期标记及北京时间日期，按 UTC 日历计算该日期所在周的周一至下周一边界，返回完成数和有效计划数。
- 按原计划日期筛选当周未取消、非免考核计划，未来计划也计入分母。正常完成、替代完成、带补做的未完成各计一次；补做实际日期不改变归属，独立的 `periodWalks` 不参与统计。
- 今天页 `onShow` 重新计算并展示“已完成 X / 应完成 Y”；零分母显示“本周无考核计划”。生理期标记及取消沿用现有刷新流程，统计随之更新。
- 仅增加今天页的进度区域和对应样式，标明北京时间周一至周日及临时记录口径。统计不修改原计划、结果或感受，不保存额外统计状态到 App。
- 本轮源码仅新增统计函数、修改今天页 JS/WXML/WXSS。新增两份测试、本文及两张截图，PRODUCT 追加本片说明。保留已有第 16、17 片未提交改动；不改周计划、记录、回看和应用状态结构。
- 不实现分类明细、原因分析、四周趋势、历史周查看入口、百分比、持久化或云开发。
