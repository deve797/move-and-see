# 切片 4：今天页显示自己安排的运动

日期：2026-09-26。范围依据根目录 `切片.md` 的切片 4。

## 修改内容

- `app.js` 提供本次运行共享的临时计划数组；周计划复用该数组，重新进入页面不清空。没有本地存储、数据库或登录。
- 今天页在 `onShow` 按北京时间当天日期筛选未取消安排，按开始时间升序排列；每次返回或重新显示页面均刷新。
- 卡片使用实际项目和开始时间，文案显示当天安排数量；无安排显示“今天没有安排”，不填充固定示例。
- 移除今天卡片的示例时长、完成切换及跳向固定示例记录的入口；原记录页和回看页未改动。
- 复用瑜伽、跑步已有动画，其他项目使用普通卡片。同类多条组件 ID 唯一，修改项目时重建对应动画组件。
- 已有心情弹层保留为标注清楚的界面演示：只写今天页视图，重新显示今天页时清空，不关联共享计划，不实现切片 9 的跨页回显。
- 更新今天页及周计划页的临时状态说明。前几个切片的“离开周计划页后不保留”在本片变为“本次运行内共享，关闭重开不保留”。

没有加入结果记录、周进度、提醒或其他后续切片；没有重构无关页面。
