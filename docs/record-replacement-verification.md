## 实现与边界

- 无结果的有效计划增加“这次做了其他运动”入口，实际项目从已有六项运动中单选，默认不选。
- 确认只在原计划上写入一份 `result: { status: 'replacement', actualActivity }`。保留原计划及运动前感受，不迁移未确认的跑步草稿。
- 记录页显示原计划和实际项目；今天页、周计划显示“替代完成 · 实际散步”等对应结果。重复确认、旧页面确认、取消或无效计划均不能新增或覆盖结果。
- 替代结果不开放原有按计划完成专属的跑步字段、体感、运动后感受和结果修正；本轮未定义这些转换，不自行扩展。
- 仍只在本次运行内临时保留；没有新增统计、持久化、服务、依赖或测试框架。
