## 配对与周范围

五档从低到高为：低落、不太好、一般、不错、很好。只比较合法且完整的前后值，不从备注推断，不以空值当最低档。

| 记录 | 配对来源 |
| --- | --- |
| 按计划完成 | `plan.beforeMood` 与 `result.afterMood` |
| 替代完成 | `result.beforeMood` 与 `result.afterMood` |
| 未完成后补做 | `result.makeup.beforeMood` 与 `result.makeup.afterMood` |
| 待记录、未完成且未补做 | 不参与 |

当前替代运动没有感受采集入口，补做仅有运动后感受入口。因此这些实际记录缺少完整配对时不参与；测试中的完整替代/补做配对是汇总层样例，不代表新增了采集能力。原计划运动前心情不会与补做或替代运动的心情拼接，独立自愿散步也不会借用原计划心情。

spec 没有单独规定心情的跨周归属。本轮采用最小范围假设：沿用本周回看的原计划日期，按北京时间周一至周日筛选，页面已说明。取消计划排除；免考核仅影响完成率，不排除实际已运动且前后心情完整的样本。
