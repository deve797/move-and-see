# 切片 15：为未完成计划补做

日期：2026-09-26。范围依据 `切片.md` 第 15 片和本轮确认的 Goal / Acceptance / Feedback / Stop Conditions。

## 实现与边界

- 原计划与 `result.status: 'incomplete'`、`result.reason` 保留，只追加一份 `result.makeup: { date, actualActivity }`。跨周也不搬移或新建计划。
- 日期和实际项目必选。日期必须真实有效，不早于原计划日期、不晚于北京时间今天，同日补做允许。实际项目复用现有六项运动，不新增项目管理。
- 放弃、未确认离页不写入；确认重新核对计划、原结果对象、原因和输入。重复确认、旧页确认、取消或删除目标均不能新增或覆盖补做。
- 补做体感写入 `makeup.feeling`，心情与备注写入 `makeup.afterMood` / `makeup.afterMoodNote`。感受页展示实际项目和补做日期，不使用原计划开始时间。
- 原运动前感受不迁移、不覆盖。感受确认保护原结果和补做对象身份，并检查载入时心情/备注是否已被更新；体感修改不阻断独立心情确认。
- 已补做计划关闭普通修正入口；旧修正页确认也拒绝清除补做。未补做计划的原修正行为保留。
- 沿用运行内临时状态与演示说明。不新增多次补做、提醒、修改/撤销流程、跑步数据、统计、持久化、依赖、服务或测试框架。
