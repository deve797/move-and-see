# 今天页运动前心情入口

> 历史验证记录。当前五档心情、运动前文字备注及“完成”交互以 [最新验证记录](mood-consistency-verification.md) 为准。
2026-09-26。用户确认在今天页每张运动卡片内加入运动前心情入口，以底部小面板选择；保留原页面和导航结构。

## 本轮修改

- `miniprogram/pages/today/index.wxml`：每张运动卡片内增加独立心情按钮；原生 page-container 底部面板、五档表情和关闭入口；弹层打开时卸载装饰动画，避免 Canvas 浮到面板上方。
- `miniprogram/pages/today/index.wxss`：卡片内 48px 心情入口、底部面板和可编辑的几何表情、320px 适配。
- `miniprogram/pages/today/index.js`：每项运动独立、初始空白的示例心情；打开、选择、回显、关闭及原生退场状态处理。
- 本报告及四张 `today-mood-*.png` 截图。

未新增页面或路由。现有卡片内容仍进入运动记录，完成圆点仍只切换状态，周计划与回看入口保留。43 个非目标小程序源码/素材 SHA256 与修改前备份一致。

## 使用与范围

点击卡片底部“运动前心情 · 点一下记录”，弹出对应项目和时间的面板。五档为低落、不太好、一般、不错、很好；没有默认值。选完自动收起，卡片显示选择，再点可修改。关闭或点遮罩不改变已选值。瑜伽与跑步彼此独立，不影响完成状态。

选择仅保留在当前今天页实例，返回该实例时仍在，重新进入恢复空白。不写数据库、本地存储或网络，不传给运动记录页。本次仅供前端试用。

## 相对讨论方案的调整

入口放在卡片内底部的独立一行，而不是覆盖在时长与插画之间，避免遮住现有运动动画；原卡片内容布局不变。面板打开时暂停并隐藏装饰动画，关闭后恢复，解决微信 Canvas 层级覆盖问题。文字、入口、表情、按钮都用 WXML/WXSS，实现中没有新增图片。
