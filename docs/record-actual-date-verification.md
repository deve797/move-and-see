# 实际运动日期与记录页精简

2026-09-27。用户确认实际运动只记日期，暂不记录开始、结束时间，并减少页面说明文字。

## 当前行为

- 新完成与替代完成保存 `result.actualDate`。计划当天默认记当天，不要求多选一次，也不受计划开始时刻限制。
- 补记旧计划必须选择实际运动日期，范围为原计划当天至北京时间今天。实际日期等于计划日期按普通完成或替代完成展示；晚于计划日期归为补做。填写时间不用于推断运动日期。
- 未来计划不能首次提交完成、替代或未完成。结果修正为完成同样检查实际日期。
- 原计划项目、日期和时间保留。今天、周计划、回看及运动后感受页使用实际日期展示；实际运动不沿用计划时刻。跨周完成仍归原计划所在周，不重复计数。
- 跨日运动不把原计划运动前心情与实际运动后心情配成同一次运动样本。历史无实际日期的已完成结果不自动补填；原有未完成后补做的原因与记录保留。
- 保存失败保留日期和草稿版本；首次确认采用的日期冻结，跨午夜重试不会悄悄换一天。未来计划带草稿跨到当天时自动带入当天日期。
- 记录页移除重复顶部说明、底部保存机制说明及重复选填提示。主按钮为“确认已完成”，次要入口为“做了其他运动”“未完成”；保留必要字段和错误提示，沿用原有视觉样式。

## 交付边界

本轮包含云函数校验与客户端改动，需要配套更新。旧云函数不接受新增的实际日期字段；新云函数要求首次完成结果包含实际日期，因此旧客户端不能继续创建缺少该字段的新完成结果。历史已有无日期结果可继续读取和保存感受，不执行自动迁移。

本轮未部署云函数、上传微信版本、设置体验版、提交审核或发布；尚未验证真实云端保存实际日期、真机及原生日期选择面板。
