# 切片 16：标记生理期当天

日期：2026-09-26。范围依据 `切片.md` 第 16 片及本轮确认的 Goal / Acceptance / Feedback / Stop Conditions。

## 实现与边界

- `App.globalData.periodDays` 按北京时间日期记录生理期标记，与 `plans`、`result` 独立。今天页只设置或取消当天；无计划时也可标记日期，不自动新增计划。
- 今天页、周计划和记录页按计划日期派生 `periodExempt`。当天有效计划统一显示免考核；新加或移入的计划自动适用，移出、其他日期和已取消计划不受影响。固定示例仍仅供展示。
- 免考核的无结果计划不提示待补记录、不要求未完成原因。记录页提示可直接返回，暂停首次未完成入口；已有完成或未完成结果保留修正入口，跨日后仍可修正，原因选填。标记变化后已打开的未完成或修正表单在确认时只刷新，不改写结果。已有补做和替代结果沿用原修正限制。
- 标记和取消不改原计划及结果，也不清空感受、跑步数据或补做。已有事实继续展示，自主完成、替代完成及原有补做/感受流程保留。取消后恢复原结果展示、待补记录及原因必填规则。
- 日期归属不随设备时区改变；午夜后旧今天页的首次操作只刷新，不把旧页面操作写入新一天。历史标记在本次运行内仍按原日期展示。
- 沿用原生 WXML/WXSS/JavaScript 与既有视觉约定；保留临时说明。无数据库、登录、持久化、散步安排、周期预测、健康建议、完成率统计、新依赖或测试框架。
