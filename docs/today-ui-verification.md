## 基本验证

微信开发者工具原生模拟器，逻辑宽度由运行时确认。

- 375px：卡片左右边界 20–355px，尺寸 335×272px；文字和插画无明显遮挡；日历和状态按钮点击区域 44×44px。
- 320px：卡片左右边界 17–303px，尺寸 286×252px；标题、说明和时间可读，无横向溢出；页面自然滚动，跑步卡片及底部说明可完整查看。
- 实际点击：主页“看看今天”进入今天页；状态圆点切换瑜伽为未完成，再次点击恢复，不触发详情跳转；跑步卡片进入详情，显示跑步、18:00、40 分钟；“返回今天”正确返回；右上日历进入周计划。
- Node 检查：JS 语法通过；切换状态不修改原始示例数组；重新进入恢复初始状态；今天/周计划两种详情来源及独立入口的返回目标正确。
- 最终运行时控制台 `error` 检索为空。
- 已检查两种宽度的顶部、底部截图。未做真机验证、未上传或发布。

## 主动调整与原因

1. 品牌沿用“向前动”，复用现有衬线字体与品牌下划线，保持项目一致。
2. 保留微信原生导航、返回与胶囊；右上日历进入已有周计划，不重复实现日期管理。
3. 两张卡片保留名称 → 开始时间 → 时长的层级。背景由 WXSS 设置为鼠尾草绿与浅灰白，完成圆点及勾线也由 WXSS 绘制；插画不包含 UI 文字。
4. 瑜伽复用已有黑白插画，省略概念图中的小盆栽；跑步场景重新生成，不做整屏截图切片，以便保持文字和背景可编辑。
5. 状态控件扩大到 44px 点击区域，与卡片导航分开；仅演示勾选变化，底部注明不保存记录，避免误认为业务已接通。
6. 短屏采用纵向滚动，保持字号与插画清晰；不把两张卡片强行挤进一屏。
7. 卡片跳转到复用的详情占位页，尚未实现真实运动记录表单。
