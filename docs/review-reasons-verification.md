# 切片 20：回看未完成原因分布

2026-09-26。范围仅对应《切片.md》第 20 片，沿用本次运行内的临时记录。

## 修改范围与口径

- `miniprogram/pages/review/index.js`：每次显示回看页时，从本周未取消计划中汇总明确填写的原未完成原因，生成原因次数与其中已补做次数。仅统计 `result.status === 'incomplete'` 且存在 `result.reason` 的计划；补做仅增加子计数，不扣减原原因次数。
- `miniprogram/pages/review/index.wxml`：在本周分类之后增加“未完成原因”，显示原因、次数、其中已补做次数；没有原因时显示“本周还没有已填写的未完成原因。”保留临时记录说明。
- 复用原回看页样式，无 WXSS 改动；没有改动 App、记录页、今天页、周计划或共享统计函数。保留工作区原有前序切片的未提交改动。
- 新增 `tests/review-reasons.test.js`、本文与三张模拟器截图；`PRODUCT.md` 追加本片能力说明。

统计范围为北京时间周一至周日、按原计划日期归属，排除已取消计划。与完成进度及结果分类不同，生理期免考核不排除已明确填写的原原因；标记及取消免考核均保留原因次数与其中补做次数。待记录、缺少或空原因、独立生理期散步不自动归因；只有明确选择“其他”才计入“其他”。结果被修正为已完成，或原因修正为空后，不再计入原因分布。

本片不实现原因推测、改善建议、跨周原因趋势、心情变化统计或持久化；原有四周图表和心情区域仍为明确标识的固定示例。
