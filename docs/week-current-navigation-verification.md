# 本周计划入口与下周切换

2026-09-26。按用户确认的“平时看本周，周末安排下周”调整现有前端入口。

## 修改文件

- `miniprogram/pages/today/index.wxml`、`index.wxss`：右上角原日历入口增加“本周计划”文字，复用日历图标，点击区域高 44px。
- `miniprogram/pages/week/index.js`、`index.wxml`、`index.wxss`：默认显示本周七天；底部“安排下周”切至下周，非本周视图可“查看本周计划”；切换后回到列表顶部，标题、说明和日期同步变化。
- `miniprogram/utils/week-preview.js`：复用既有周一计算，导出当前周周一日期，返回当前周/下周标记。
- 本文及八张 `weekly-*.png` 截图；旧周计划验证记录追加本次链接。

未新增页面、路由、图片素材、数据库、请求或持久化。既有日期选择器和详情占位页保留。其余 42 个小程序文件与修改前哈希一致；用户的 `AGENTS.md` 未修改。

## 行为边界

今天页 → 本周计划，默认周一至周日；底部“安排下周”始终可以使用，不限制为周末。下周视图保留“下周怎么动？”标题，并说明周末安排的使用场景；底部可返回本周。日期选择器仍可以查看任意日期所在周。

“安排下周”本轮只切换到下周七天的示例界面；点选一天仍进入既有详情占位页。尚未实现真实计划编辑、保存或周末提醒。各周沿用固定运动示例，并继续标注“暂不保存计划”。
