# 首页 UI 交付与验证

日期：2026-09-25。

## 实现范围

用户确认只实现《向前动概念图.png》左上首页；“看看今天”跳转到明确标注的“今天”占位页，可返回首页。无数据库、云函数、真实记录、统计或本地持久化。其余四个概念画面没有入口，本轮不额外添加页面。

项目原本只有 plan.md、概念图及 design 参考资料，没有现成代码或组件可复用。新增最小原生小程序结构，两个页面共用 app.wxss 中的品牌、字体和按钮样式。未修改原规划或原参考图。

## 新增文件清单

- project.config.json：项目入口，使用开发者工具中已核实的“向前动” AppID，源码目录 miniprogram/。
- miniprogram/app.js、app.json、app.wxss、sitemap.json：启动、页面注册、公共样式、禁止演示页面索引。
- miniprogram/pages/home/index.wxml、index.wxss、index.js、index.json：首页、适配样式、跳转及插画失败回退。
- miniprogram/pages/today/index.wxml、index.wxss、index.js、index.json：明确标注的占位页及返回操作。
- miniprogram/assets/morning-stretch.png：以概念图为参考生成的独立插画，不含任何 UI 文字、按钮。
- PRODUCT.md、DESIGN.md：本轮确认的范围和视觉约定。
- docs/ui-verification.md、home-320.png、home-320-bottom.png、home-375.png、home-375-bottom.png：本说明与原生模拟器截图。

## 验证结果

使用微信开发者工具 2.02.2608070、基础库 3.16.3。不是浏览器模拟 WXML；截图来自真实微信开发者工具模拟器。截图像素尺寸受模拟器缩放影响，以下逻辑宽度由运行时 systemInfo 确认。

| 检查 | 结果 |
| --- | --- |
| 320px / iPhone 5，320×568 | 通过。内容视口 320×504，页面约 653px 高；标题单行、说明两行，已检查元素左右边界均在 0–320px；按钮 100×100px。 |
| 375px / iPhone 6/7/8，375×667 | 通过。内容视口 375×603，页面约 763px 高；文字与插画无横向溢出，按钮 112×112px。 |
| 滚动到主按钮 | 两种尺寸均通过；按钮完整露出，有底部留白。 |
| 首页 → 看看今天 → 今天占位页 | 两种尺寸实际点击通过，页面路径 pages/today/index。 |
| 返回首页 | 两种尺寸实际点击通过，375px 页栈核实只剩 pages/home/index。 |
| 防连点、导航失败重试、返回后重新进入 | Node VM 模拟微信 API 检查通过；失败显示 Toast 并解除跳转锁。 |
| 占位页作为独立入口时返回 | Node VM 检查通过，使用 reLaunch 回到首页。 |
| 插画加载失败回退 | Node VM 检查通过，切换到文字回退，不影响主入口。 |
| JS 语法、JSON、路由文件与插画引用 | 通过。 |
| 最终 320px 原生跳转返回后控制台 error 检索 | 无匹配错误。 |

调试过程中，重新编译紧接自动化查询曾出现超时和开发者工具 routeDone/webviewId 内部错误；页面重新就绪后完成全部导航，最终新会话错误检索为空。没有做微信真机或 Android 字体验证，也没有上传体验版或发布。

## 相对概念图的主动调整

1. 按已有品牌约定，将 Move & See 换成“向前动”，橙红下划线仍由 WXSS 绘制。
2. 保留微信原生顶部导航、右上角胶囊与返回，不另画概念图的省略号、手机边框或外部投影。
3. 保留“品牌 → 标题 → 说明 → 黑白运动场景 → 圆形主按钮”的顺序和层级。插画根据参考重新生成，人物姿态、线条并非像素级复制。
4. 概念画面比测试设备更修长。为保留插画分量与可读字号，320px、375px 短屏允许自然纵向滚动；首次打开需向下滚动约 150–160px 才能完整看到主按钮。没有缩成整屏图片。
5. 中文标题使用设备衬线字体栈，缺少相应字体时自然降级。正文、品牌、背景、按钮、箭头均可在 WXML/WXSS 中编辑。
6. “今天”不展示概念图示例计划或假数据，只注明页面占位，避免把 UI 演示误认成业务已实现。
