# Move&See

一个减少日常选择的个人运动日记微信小程序。提前安排运动，记录实际完成情况与感受，回看已经发生的事实，不提供训练指导或评价。

使用原生 WXML / WXSS / JavaScript 开发，通过 CloudBase 云函数与文档数据库保存记录。

## 主要功能

| 功能 | 当前能力 |
| --- | --- |
| 周计划 | 按周查看安排，新增运动项目与开始时间，修改或取消尚未开始且没有结果的安排 |
| 今天 | 查看当天真实计划、待记录事项和本周完成进度 |
| 运动记录 | 记录按计划完成、未完成原因、替代完成和补做；支持符合条件的结果修正 |
| 数据与感受 | 跑步时长、距离、心率手动填写与平均配速显示；运动前后心情、备注和体感按对应入口选填 |
| 日期标记 | 标记当天生理期，自愿选择散步 30 分钟；周计划可查看已保存的历史散步状态 |
| 回看 | 本周结果分类、未完成原因、有效样本的前后心情变化、原话记录，以及近四周完成情况 |
| 分享 | 首页、今天页及页面菜单支持转发；分享固定进入首页，不携带个人记录或感受 |

固定示例有明确标识，不写入数据库，也不参与真实统计。补做、替代运动与普通完成的录入字段和修正范围存在差异，以对应页面为准。

## 本地预览

1. 安装并登录微信开发者工具，使用具备对应小程序开发权限的微信账号。
2. 导入本仓库根目录，即包含 `project.config.json` 的目录。
3. 确认 AppID 与所使用的小程序一致；工具会按配置读取 `miniprogram/` 和 `cloudfunctions/`。
4. 确认云开发环境、数据库集合及 `moveSeeApi` 已配置并可访问，然后点击编译。

前端无需 `npm install`、npm 构建或额外打包步骤。真实记录的读取与保存依赖网络和已部署的云函数，导入源码不等于云端服务已就绪。

## 云端配置与数据

仓库已包含原项目的 AppID 和环境 ID。复用到自己的小程序时，需要同步修改以下配置，并在自己的环境中创建资源：

| 配置位置 | 用途 |
| --- | --- |
| `project.config.json` → `appid` | 微信开发者工具使用的小程序 AppID |
| `miniprogram/app.js` → `getStore()` 中的 `env` | 前端调用的 CloudBase 环境 ID |
| `cloudbaserc.json` → `envId` | 云函数部署目标环境 |
| `cloudfunctions/moveSeeApi/api.js` → `APPID` | 云函数允许的小程序身份 |

云端需要两个集合：

- `plans`：运动计划、结果、跑步数据与感受。
- `day_marks`：按日期保存的生理期标记与自愿散步。

两个集合均采用 `ADMINONLY` 权限，关闭客户端直接读写，由云函数处理访问。集合中同时存放业务记录（`_kind: record`）和用于防止重复提交的请求回执（`_kind: request`），因此集合文档总数不等于计划数量。

事件云函数名为 `moveSeeApi`，入口为 `index.main`。仓库部署配置使用 `Nodejs18.15`，并在部署时安装 `cloudfunctions/moveSeeApi/package.json` 声明的依赖；这与前端无需安装依赖是两回事。详细配置与既有验证见[数据库接入记录](docs/database-connection-verification.md)和[分享与多人使用验证](docs/share-verification.md)。

### 保存与权限规则

- 云函数只信任本次调用上下文中的微信身份，检查 AppID，并按调用者 OPENID 隔离记录；不依赖客户端传入的用户身份。
- 当前代码已取消本人白名单，不再使用 `OWNER_OPENID` 鉴权，也不需要为新用户配置该变量。
- 只有云端保存成功后才更新页面中的记录；请求重试有去重保护，旧版本提交会提示冲突，避免覆盖新内容。
- 读取失败不会用不完整的结果覆盖已有缓存。仍存活的页面实例会保留未提交草稿和保存错误；尚未提供进程退出后的本地草稿恢复。
- 分享入口不授予访问权限。体验版仍需在微信公众平台配置体验成员，各账号只访问自己的记录。

### 统计口径

按北京时间、周一至周日和原计划日期归属统计。已取消及生理期免考核的计划不计入应完成数量；按计划完成、替代完成、已补做各计一次。跨周补做归入原计划所在周，自愿散步不计入完成进度；无有效计划时显示“本周无考核计划”。心情比较只使用同一次实际运动的完整前后样本，不从文字推测感受。

## 项目结构

```text
.
├── miniprogram/                 # 小程序源码
│   ├── app.js                   # 云端存储初始化与共享状态
│   ├── app.json                 # 页面注册
│   ├── pages/                   # home、today、week、record、mood、review
│   ├── components/              # 运动动画组件
│   ├── utils/                   # 云端存储、统计、配速及分享等逻辑
│   ├── styles/                  # 共享样式
│   └── assets/                  # 页面插画与动画素材
├── cloudfunctions/moveSeeApi/   # 身份校验、数据校验、事务与访问接口
├── tests/                      # Node.js 自动测试与模拟运行环境
├── docs/                       # 专项验证记录与截图
├── design/                     # 视觉参考与素材说明
├── project.config.json         # 微信开发者工具配置
└── cloudbaserc.json            # 云函数部署配置
```

## 自动验证

在项目根目录使用 Node.js 18 或更高版本运行现有测试，无需安装测试依赖：

```sh
node --test tests/*.test.js
```

单独检查运动动画逻辑：

```sh
node tests/exercise-motion.test.js
```

测试覆盖页面行为、统计口径、保存失败恢复、版本冲突、请求去重及多用户数据隔离。测试使用模拟的微信与数据库环境，不写入真实云端，也不能替代微信开发者工具或真机验收。
